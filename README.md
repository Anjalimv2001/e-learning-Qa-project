# E-Learning Application — QA Testing Project

A portfolio QA project demonstrating an end-to-end manual testing workflow.

## QA Flow

Application → Test Plan → Test Cases → Test Execution → Bug Reports → Retesting → Regression → Test Summary

## Coverage

- 70 test cases
- Functional testing
- Negative testing
- Regression testing
- Retesting
- API testing
- UI testing
- Security validation
- Accessibility checks
- Performance checks
- 12 documented defects
- 6 retested defects
- 12-case regression suite

## Project Structure

| Folder | Contents |
|---|---|
| `01-Test-Plan` | Test strategy, scope, environment and entry/exit criteria |
| `02-Test-Cases` | Detailed test cases |
| `03-Test-Execution` | Execution results and traceability |
| `04-Bug-Reports` | Defect records with severity/priority |
| `05-Retesting` | Verification of fixes |
| `06-Regression` | Regression suite after fixes |
| `07-Test-Summary` | Final testing summary |
| `screenshots` | Add only screenshots you actually captured |

## Tools

Manual Testing • Postman • SQL/MySQL • JIRA • Git/GitHub • Chrome DevTools

## How to Explain This Project

"I tested an e-learning application end to end. I designed and executed manual test cases across core workflows, documented defects with severity and priority, performed retesting after fixes, and executed regression testing to make sure existing functionality was not impacted."
