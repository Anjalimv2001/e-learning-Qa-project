# E-Learning Application — Test Plan

## 1. Objective
Verify that the e-learning application works correctly for learners and authorized staff, with emphasis on functional workflows, validation, API behavior, security and regression.

## 2. Scope
### In Scope
- Registration and login
- Profile management
- Course search/listing/details
- Enrollment and payment workflow
- Video lessons and progress
- Quizzes and scoring
- Certificates
- Notifications
- Instructor/admin authorization
- API validation
- UI, accessibility and performance checks

### Out of Scope
- Internal implementation of third-party payment providers
- Production infrastructure penetration testing
- Full load/stress testing

## 3. Testing Types
- Functional
- Negative
- Smoke
- Sanity
- Regression
- Retesting
- API
- UI/Compatibility
- Security validation
- Accessibility
- Performance checks

## 4. Test Environment
- OS: Windows
- Browser: Chrome
- API tool: Postman
- Database validation: SQL/MySQL where applicable
- Defect tracking: JIRA-style defect records
- Test execution: Manual

## 5. Entry Criteria
- Test environment available
- Application build available
- Test data available
- Required user accounts available

## 6. Exit Criteria
- Planned test cases executed
- Critical/high defects documented
- Fixed defects retested
- Regression suite completed
- Test summary prepared

## 7. Deliverables
- Test Plan
- Test Cases
- Test Execution
- Bug Report
- Retesting Report
- Regression Report
- Test Summary Report
